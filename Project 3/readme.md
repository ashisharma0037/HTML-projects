# TechPulse News

## 📘 Project Overview
TechPulse News is a basic technology news webpage built using HTML.  
It displays featured technology content, navigation links, and a header image to provide a simple news-portal layout.

## 🎯 Objectives
- To design a simple front-end layout using HTML.
- To include images, headings, navigation links, and structured content sections.

- Newsroom image file
